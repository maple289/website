# MyHostage - User Guide

**Website:** [myhostage.ca/video/](https://myhostage.ca/video/)

**Updated:** November 17, 2026. Guide to the current version of the application.

**Purpose:** videos, photos, files, private messages, and voice/video calls.

Button names match the interface. Available actions depend on your permissions and browser capabilities. The PDF includes updated screenshots of the live website: the home page, group uploads, notification settings, Share, File Storage, and temporary links. Personal information is hidden or cropped out. Call and mobile-video illustrations use demonstration data; they do not replace testing on a physical phone.

## 1. Finding your way around

The top navigation opens the public libraries. After signing in, use the sidebar to open your workspace. On a phone, use the **☰** menu button.

| Section | Purpose |
|---|---|
| **Videos / Photos / Files** at the top | Public content, also available without signing in. |
| **Home** | The home page and public content. |
| **My Videos / My Photos** | Your videos/photos and content shared with you directly or through groups. |
| **File Storage** | Your files and folders, and content shared with you. |
| **Messages** | Private and group conversations, voice and video calls. |
| **Settings / Statistics** | Your profile, password, and content statistics. |

**Private** keeps content available to its owner and selected recipients. **Public** makes a video/photo public. For files, **Everyone** allows anyone, including guests, to view and download. Sharing with selected people or a group does not make content public.

In the main Videos/Photos galleries, the **Messenger group** filter is in the sidebar. **NONE** shows public content; selecting a group shows only videos/photos assigned to it. On a phone, open the menu. See section 15 for filtering and uploading to a group.

An ordinary private-content URL does not give a guest access by itself. For time-limited access, use **Create 24-hour share link** (section 7).

## 2. Registering, signing in, and signing out

1. Select **Sign in → Create one**.
2. Enter your email. **First Name / Last Name** are optional. You do not create a password when submitting the request.
3. Select **Request account** and wait for administrator approval. Do not resubmit a successfully sent request.
4. After approval, you receive an email with a temporary password and its expiration time. Enter your email and that password in the usual **Sign in** fields. The temporary password is valid for **one hour from issuance**; the time in the email is in UTC.
5. Complete **New Password / Confirm New Password** and save. Your permanent password must differ from the temporary one. Use the permanent password for future sign-ins.

If the email is missing or the temporary password has expired, check Spam, enter your approved email in Sign in, and select **Request temporary password**. Wait one minute before requesting another. A new temporary password invalidates the previous one. The response does not confirm whether an account exists or is approved. This action is for initial password setup, not for resetting a permanent password later.

First-time sign-in no longer uses a blank password. If you refresh before saving a permanent password, sign in again with your still-valid temporary password. If the email is already in use, use the existing account or a different address. A normal sign-in opens **Home**.

**Sign out** is in the account menu. Use it when finishing on a shared device. Signing out ends the active call on this device and releases its microphone/camera. Ending sessions on other devices requires a server connection.

Messages and calls use the same sign-in. You do not need to sign in again for each call. If a session-check error appears after returning from the background, see section 14.

## 3. Uploading content

1. Open **My Videos**, **My Photos**, or the destination folder in **File Storage**.
2. Select **Upload** or drag files into the marked area. You can select multiple files.
3. For videos and photos, choose **Private / Public**. A single-file upload also lets you enter a title.
4. Wait for file transfer to finish before closing the tab.

Upload videos and images to their respective sections. File Storage accepts different file types within the site's limits and saves them in the open folder. One failed file does not cancel the other uploads.

If a group is selected in the main gallery, **Upload** and drag-and-drop target that group. Check **Upload to group** before selecting files: content remains private, you remain its owner, and members gain access after processing. With **NONE**, or when uploading from My Videos/My Photos, the normal personal-upload flow applies. See section 15.

| Video status | What to do |
|---|---|
| **Uploading** | The file is being transferred; keep the tab open. |
| **Processing** | The server is processing the video; you can use other sections. |
| **Ready** | The content is ready to view. |
| **Processing Failed** | Read the error. Use **Retry Processing**, if available, or **Delete Failed Upload** with confirmation. |

Buttons are disabled while an operation is pending. Wait for the result before repeating an action.

## 4. Viewing content and using item menus

Select a ready video/photo card. **Search**, filters, and sorting help you find content. **Comfortable / Compact** change gallery density when these controls are shown.

The round **⋮** button opens a video, photo, file, or folder menu. The menu appears over the page and repositions near screen edges. Selecting an action closes it; on a phone, tap the button.

Your own items may offer **Edit**, **Rename**, **Share**, **Create 24-hour share link**, **Make public / Make private**, **Download**, and **Delete**. Other people's items show only permitted actions, such as **Play / Preview / Download**. Guests can view public content; downloading through the interface requires sign-in. **Move / Copy / Paste** apply only to files and folders.

**Edit** changes settings for your videos/photos; **Save** saves them. For a video, you can configure its preview image. **Rename** changes the item's name.

| Viewing photos | Controls |
|---|---|
| Computer | **→ / Space**: next; **← / Alt + Space**: previous. |
| Mouse | Scroll down: next; scroll up: previous. |
| Phone / tablet | Swipe left/right. Double-tap the photo to enter/exit fullscreen; this does not zoom into a particular area. |

Close with **X / Close**. Choosing a different reaction replaces your current one; selecting your applied reaction again removes it. Adding a reaction requires sign-in; reaction counts let you see who reacted.

Ordinary video controls, Fullscreen, Picture-in-picture, and iPhone behavior are covered in section 17. Sections 10-12 cover calls.

## 5. Files: Copy, Paste, and Move

In File Storage, **New folder** creates a folder. Use the path at the top and browser Back/Forward to navigate. **Grid / List / Tree View** switch views. Search finds names in accessible folders; in the public library, it searches public content only.

| Action | Steps |
|---|---|
| **Copy** | Select Copy in your file/folder menu. The original stays where it is. |
| **Paste / Paste here** | Open the destination folder. Select Paste in the toolbar or Paste here in an available menu. A copy is created in the current folder. |
| **Move** | Select Move, choose the destination folder, and confirm. After a successful move, the item is no longer in its original location. |

A folder is copied/moved with all its subfolders and files. You cannot move a folder into itself or one of its subfolders. You need permission to write to the destination; being able to view someone else's folder does not give you write access.

The Copy clipboard is temporary and belongs to the current account. Paste needs a valid source. After signing out, switching accounts, or reloading, select Copy again. Deleting a pasted copy does not clear the original from the clipboard: you can paste it again while the source remains available.

If names conflict, choose **Replace** (replace after a separate confirmation), **Keep both** (keep both with different names), or **Cancel**. The replaced item moves to Trash. Nothing is overwritten without your choice.

**Preview** opens supported PDFs, images, text, CSV, and Office files. **Generating preview…** means preparation is in progress; the original is unchanged. Use Download for other formats. Folders download as ZIP archives within the site's limits. For partial failures, read the message and retry the remaining steps in the same dialog.

## 6. Ongoing access: Share and Everyone

**Videos and photos:** select **Share** in your item's menu. In **Share video / Share photo**, set **Visibility**, add recipients through **People**, select **Groups**, and choose **Save**. You can share private content with individuals or Messenger-group members. Recipients see it in My Videos/My Photos and can view and download it; the owner keeps control of the original.

A larger screenshot with explanations is in section 18.

**Files and folders:** select recipients in Share and choose **Save sharing**. The inheritance rules below apply to File Storage; section 15 explains group access to videos/photos.

**Everyone** also allows guests access. Read the warning before enabling it. If access is for specific people, select those recipients instead of Everyone.

| Folder action | Effect on access |
|---|---|
| Share a folder | Current and future files and subfolders inherit access. |
| Remove direct access to a nested file | Inherited access may remain. Change Share on the indicated parent folder. |
| Move a file | Direct permissions follow the file; inheritance depends on its new folder. |
| Copy a file | The copy inherits its destination folder's access; the source's direct permissions are not copied. |

To revoke saved access, change recipients, groups, or visibility and save. Removing access requires a separate confirmation naming the item and recipients. Other permissions still apply: clearing one selection does not remove public access, access through another group, or a valid temporary link. Downloaded copies cannot be recalled. If settings changed in another tab, close and reopen Share, check the current values, and save again.

## 7. Temporary 24-hour links

An owner can give guests access to a specific video, photo, file, or folder without requiring sign-in.

1. Open **⋮ → Create 24-hour share link**.
2. In **Temporary Share Link**, select **Create 24-hour share link** if a link has not been created yet.
3. Check **Valid until**, the date and time when access ends.
4. Select **Copy Link** and send the link to the intended recipient.
5. To end access earlier, reopen this dialog, select **Revoke**, and confirm.

**Copy the complete address from the dialog.** Keep `/video/` if it is part of the generated link. Do not replace the link with the ordinary item URL.

The link lasts **exactly 24 hours from creation**; viewing does not extend it. Normal Private/Public and saved Share settings stay the same. An item has one temporary link: **Create new link**, after confirmation, disables the previous one. Deleting the item or moving it to Trash ends access.

Copy the link immediately after creating it. Reopening the dialog does not recover the old address: save the link separately or use Create new link. If Copy Link fails, select the address and copy it manually.

| What the visitor sees | Meaning |
|---|---|
| The item or the specified folder's contents | The link is valid. It does not open other folders, your profile, settings, or management tools. |
| **This share link has expired.** | The 24 hours have elapsed; ask the owner for a new link. |
| **This share link is no longer available.** | The link was revoked or replaced, or the content is unavailable. |

Anyone who receives the link can open the allowed content until it expires. Do not publish it if access is intended for specific recipients. Revoking a link does not remove downloaded copies.

## 8. Messages: finding a person

Open **Messages** after signing in. The list includes active registered users you are allowed to message. It excludes your own account, invalid accounts, and people blocked by either side.

**On a computer:** **Conversations / Groups** and **People** are on the left. People stays visible during a conversation. **Search people** searches names/emails; select a person. Conversation and people lists scroll separately.

**On a phone:** select **New message**. **New conversation** opens with a ready-to-use list. **Find registered users** filters names/emails. Select a person: once the conversation opens successfully, the dialog closes and messages appear. **Back to conversations** returns to the list.

**More people** loads the next part of a long list. You can search from one character. A person's first/last name is shown, or their email if no name is set. The green indicator/Online shows presence; Offline means no active session. A number beside a person/conversation is the unread-message count.

Selecting a person opens the existing private conversation or creates one new conversation; selecting them again does not create a duplicate. The current conversation is highlighted. Groups stay in Conversations / Groups. If a person becomes unavailable after the list loads, an error appears; check the list again.

## 9. Messages, groups, and blocking

Type a message and select **Send**. Use the attachment button to add a file and wait for its transfer to finish. Messages offer **Reply** and reactions; your own messages also offer **Edit** and permitted deletion options.

To create a group, use **Create Group** in the Messages menu or **New message → Group conversation**. Enter **Group name**, select members, and choose **Create group**. Groups support up to 50 members, including you. You can remove selected people from the draft before creating the group.

The search on the left finds conversations/member names. **Search conversation** searches inside a conversation. Scroll up to load older messages; **Go to latest messages** returns to the newest ones.

| Action | Effect |
|---|---|
| **Mute / Unmute** a conversation | Changes your notifications; messages and unread counts remain. |
| **Block user** | Blocks private messages between you in both directions. History and shared groups remain. |
| **Blocked users → Unblock** | Removes your block. The other person's block may still apply. |
| **Leave group** | Ends your further access; messages you sent remain for other members. |

In the group menu, **Edit Group** changes the name (**Save name**). **Manage Members** lets the owner/group administrator manage members within their permissions. Only the owner appoints group administrators. New members can access existing history and content shared with the group. If the owner leaves, ownership passes to the longest-standing group administrator, or, if none, the longest-standing member.

**Delete Group with Content** is available to the owner or a site administrator after confirmation; being a group administrator alone does not grant this permission. Original library videos/photos remain. See sections 13 and 15 for the effects of deletion and leaving.

When using Cancel/Close with a draft, **Keep Editing** preserves your work and **Discard** abandons changes. Clicking outside or pressing Escape does not close the task dialog. Wait for pending requests to finish.

## 10. Making a voice or video call

A conversation has two buttons: **Voice call** with a phone icon and **Video call** with a camera icon. You need an active account, permission to use the conversation, and browser support for your devices.

| Type | Permissions and appearance |
|---|---|
| **Voice call** | Microphone only. Name/initials, status, duration, and audio controls; no large video area. |
| **Video call** | Microphone and camera. The other person's video is the main image; your small mirrored self-view appears over it. |

The incoming screen shows **Incoming voice call / Incoming video call**. **Accept** answers; **Decline** rejects. A ringtone plays if the browser allows it. **Enable call sound** enables ringing; **Mute ringing / Unmute ringing** affect only the invitation sound.

**Mute / Unmute** turns your microphone off/on, **Devices** opens device settings, and **End call** ends the call. Calls support up to four participants, including you; call buttons may be unavailable in larger groups.

This version cannot switch a voice call to video with one button. End the voice call and start Video call instead. Keep the tab open during a call.

## 11. Video calls: camera and fullscreen

The other person's video is the main image. Your smaller self-view starts in the upper-right corner. Your self-view is mirrored; the remote video is not. Drag your self-view to a safe corner or select **Move self-view to next corner**.

| Button | What changes |
|---|---|
| **Hide self-view / Show self-view** | Your display only. The other person still receives your camera. |
| **Camera off / Camera on** | Transmission of your camera image. Audio and the call continue. |
| **Expand call / Exit fullscreen** | Expands the whole call, including video, self-view, and controls; returns to the normal view without ending the call. |
| **Share screen / Stop sharing** | Screen sharing, if supported. Choose the area and permission in the system dialog. |

When a camera is off, a black background with **Camera off** replaces its image; the last frame should not remain. Turning it on restores live video automatically. This also applies to your self-view. Screen sharing may remain visible while the camera is off.

Fullscreen preserves the image's proportions, so black bars are normal. Bottom controls remain available. Leaving fullscreen is not End call. If browser fullscreen is unavailable, the call fills the visible page area; system bars may remain.

## 12. Phone calls: screen and audio

Rotating your phone changes the layout without restarting the call. In landscape, controls are more compact, self-view is smaller, and buttons stay within the visible area. **Expand call** uses the available space. Long settings in Devices scroll separately.

| Preferred phone output | When it applies |
|---|---|
| Video: speakerphone | If the browser recognizes and allows selection of the loudspeaker. |
| Voice: earpiece | If the browser recognizes and allows selection of the internal earpiece. |
| Headset/Bluetooth | The system route is preserved; the app should not switch audio back to the phone on its own. |

**Speaker on** is highlighted only when the loudspeaker is confirmed. **Speaker off** means the earpiece is confirmed. Selecting again switches between them if both are available.

A neutral **Speaker** button and the **Audio output** label may mean the system route, a headset, or an unknown output. They do not confirm speakerphone use. **Speaker / Devices** open the options; **Choose audio output** appears only when supported.

On some Android phones using Firefox/Chrome and iPhones using Safari, the site cannot select the physical speaker. Use your phone's system controls or a headset; the call continues. Computers use the normal system output and any available choice in Devices.

The output is retained for the call; fullscreen, rotation, and hiding self-view do not reset it. If a device disconnects, check the system route and select an available output again.

## 13. Settings, statistics, and deletion

**Settings:** edit First Name/Last Name and save your profile. **Change Password** requires your current password, a new password, and confirmation. **Statistics** shows your content, views, reactions, uploads, and storage; select a chart period. **Admin Console** is for administrators only.

In **Settings → Notifications**, set preferences and enable notifications for this device (section 16). In administrator statistics, **Reset All Statistics → Reset All**, after confirmation, restarts view and activity counts. **Statistics since** shows the new starting point. Users, content, messages, and sharing settings remain.

Before deleting, check the item's name or selected count. Deleting a folder includes its contents. **Cancel** cancels; buttons are disabled during the request. Errors stay in the confirmation: follow the message and retry only unfinished steps.

| Where you delete | Result |
|---|---|
| **My Videos / My Photos → Delete**, failed upload | Permanently deletes the item and associated files. The site cannot restore them. |
| **File Storage → Delete / Move to Trash** | Moves to Trash. **Restore** brings it back and offers a choice if names conflict. |
| **Trash → Delete forever / Delete All** | Permanently deletes the selected item or Trash contents, as stated in the confirmation. |
| **Delete for myself** on a message | The entire message card disappears only for you. Others keep the message and attachments. |
| **Delete for everyone** on your message | The card disappears for everyone; reactions are deleted and attachment access is revoked. A reference to the deleted original remains only in replies to it. |
| **Clear messages** | Clears the confirmed history for you only, or for everyone if permitted. New messages are outside the confirmed range. |
| **Delete chat** for yourself in a private conversation | Hides the conversation. Selecting that person or receiving a new message restores it without creating a duplicate. |
| **Delete Group with Content** | Permanently deletes the group for everyone: history, reactions, calls, and group permissions to library content. Messenger attachments and previews are queued for cleanup. Original library videos/photos remain. |

Deleting a group for yourself means leaving: further access to its conversation and group-shared content ends, while sent messages remain for others. Site administrators have **Manage all groups (Site Administrator)** in the Messages menu. This directory allows group deletion but does not open private group history. Hide self-view, Mute, and leaving fullscreen do not end a call.

## 14. Troubleshooting

| Problem | What to check |
|---|---|
| A person is missing from People | Name/email, More people, account activity, and blocks. An administrator can check account approval. |
| A link returns **404** | Copy the full address through Copy Link, including `/video/` if present. If the correct URL returns 404, tell the owner/administrator; guests do not need to sign in. |
| A link expired/was revoked | The owner creates a new link. Viewing or refreshing the old one does not extend it. |
| The folder is empty after Delete, but the file is in Trash | This is recoverable deletion. Restore brings it back. You can paste the source again; a conflict with an existing item requires Replace / Keep both / Cancel. |
| Paste is unavailable | Copy an existing item you own, open a permitted destination, clear search, and wait for the current operation. |
| Camera/microphone unavailable | Site permissions, Devices selections, or another app using the hardware. Voice calls do not need a camera. |
| No incoming ringtone | Enable call sound, Mute ringing, and device volume. |
| You cannot hear the other person | Volume, Audio output/headset, and their microphone. A neutral Speaker button does not mean speakerphone is enabled. |
| Sign in appears after backgrounding | Return to the tab and check the connection. Save drafts/wait for uploads, then refresh. Sign in again if the session expired. |
| Sign out does not finish | Check the account menu. If private sections remain accessible after refreshing, contact an administrator; do not leave the account open on a shared device. |
| A landscape call does not fit | Close Devices, use Expand call, and check browser zoom. If it persists, report the phone model, browser, and orientation. |
| Temporary password does not work | Check the latest email and one-hour expiry. A replacement invalidates the previous password; an already configured account needs its permanent password. |
| Group gallery is empty | Check Messenger group. Groups show assigned content only; NONE returns to public content. Use Retry groups or the available reload action after an error. |
| Access to private content disappeared | The owner may have revoked access, deleted the group, or removed you. Ask them to check People/Groups; a saved viewing URL does not replace permission. |
| No background notifications | Settings → Notifications, Enable Notifications on this device, browser permission, and conversation Mute. On iPhone/iPad, open the Home Screen app (section 16). |
| Fullscreen/PiP disappeared during a video | Tap the viewer to restore controls. They remain available while paused or seeking. Switch PiP and fullscreen in sequence (section 17). |

When asking for help, include the section, action, and exact error. For calls, add Voice/Video, browser, device, headset, and whether you switched to the background. Do not publish passwords, private conversations, or active temporary links.

## 15. Groups: galleries, uploads, and access

**Messenger group** in the main Videos/Photos sidebar lists groups you belong to, including empty ones. **NONE** opens all public content. Selecting a group shows only videos/photos assigned to it, whether private or public. The filter follows you between Videos and Photos; My Videos/My Photos show your personal and shared library independently.

Selecting a filter does not move content or change access. If you are removed or the group is deleted, it disappears from the list and the filter returns to NONE. If groups fail to load, use **Retry groups**. An empty result does not mean your originals were deleted.

To upload directly to a group, select it in the main gallery, then choose **Upload video / Upload photos** or drag in files. The dialog shows **Upload to group** and its name. Single and batch uploads stay private; you remain the owner. Videos appear after processing and photos after preparation finishes. The gallery stays on the selected group.

Check the destination before submitting: an open form keeps its original group. If your membership ends or the group is deleted before publication completes, the upload may fail; content should not silently publish to your personal library. Follow the form's error message, then choose an available group or a normal personal upload.

To share an existing video/photo with a group, use **⋮ → Share → Groups → Save** (section 6). New members gain group access; members who leave or are removed lose it. Independent access through a person grant, another group, public visibility, or a temporary link remains.

Deleting a group permanently removes its conversation and group permissions. Original library videos/photos, their preview images, and independent permissions remain. Files attached directly to Messenger messages are part of the deleted group's content. Downloaded copies cannot be recalled.

## 16. Message and call notifications

Open **Settings → Notifications**. Set **New messages**, **Incoming voice calls**, **Incoming video calls**, **Show message previews**, and **In-site notification sounds** separately. Turn previews off if message text should not appear in notifications. Wait for each change to save; check the toggle's state if an error occurs.

Select **Enable Notifications** and allow notifications in your browser. This enables background delivery **for the current device**. Enable it separately on other devices. **Disable on This Device** turns delivery off here while keeping messages and conversations. If permission is blocked, change it in browser/device settings and return to the site.

| Where you are | Notification behavior |
|---|---|
| Site open and active | A compact message or incoming-call card. A separate new-message card is suppressed for the conversation already open. |
| Tab in the background or site closed | A system notification, if delivery is enabled on the device, the browser supports it, and permissions are valid. |
| iPhone / iPad | Background notifications require iOS/iPadOS 16.4 or later and the site added to your Home Screen. Open the installed app and enable notifications there. |

Selecting a notification opens the conversation or call invitation; sign in first if needed. Calls are not answered automatically: use **Accept**. Dismissing a notification does not delete a message or decline a call. Showing a notification alone does not mark a message as read.

**Mute** suppresses a conversation's notifications while preserving history and unread counts. Sound depends on browser/OS settings and permissions; in-site sound may require normal interaction with the page. Signing out clears the account's local notification binding. After switching accounts, enable the device again for the new user.

If **Background delivery is temporarily unavailable** appears, keep using the site and try enabling later. A notification cannot bypass revoked group access. A previously displayed notification on a sleeping device may not disappear immediately.

## 17. Watching videos: Fullscreen and PiP

This section covers library videos and supported videos in file previews. For video calls, see sections 10-12.

Select a card or **Play**. Browser player controls handle playback, volume, and seeking; their appearance depends on the browser. When a video finishes naturally, its viewer closes automatically. **Close video player / X** closes it earlier and stops playback. Open the card again to replay it.

| Action | Result |
|---|---|
| **Fullscreen / Enter fullscreen** | Fullscreen video; if a suitable system mode is unavailable, the viewer fills the available page area. |
| **Exit fullscreen** | Returns to normal viewing without closing the player. |
| **Picture-in-picture** | A separate floating window, if the browser supports PiP. |
| **Exit PiP** | Returns from the floating window. Exit PiP before entering Fullscreen; exit fullscreen before entering PiP. |
| Double-tap the video area | Toggles fullscreen on supported touch devices. Do not use buttons, the seek bar, or reactions for this gesture. |

On an iPhone in landscape, normal viewing uses more of the available height. Fullscreen/PiP controls overlay the video and hide automatically during playback without interaction. Fullscreen controls also hide when idle. Tap the screen to restore them; pausing, seeking, or waiting for data brings them back. The browser manages its native playback bar.

Video proportions are preserved, so black bars are normal. Rotating the screen does not require reopening the card. Fullscreen/PiP availability depends on the browser and current mode; lack of support does not mean the content is faulty. If loading fails, check the connection and use **Retry**, if shown.
