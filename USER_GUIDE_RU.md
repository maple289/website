# MyHostage - руководство пользователя

**Сайт:** [myhostage.ca/video/](https://myhostage.ca/video/)

**Обновлено:** 11 октября 2026 года. Руководство для обновленной версии приложения.

**Назначение:** видео, фотографии, файлы, личные сообщения и голосовые/видеозвонки.

Названия кнопок сохранены на английском, как в интерфейсе. Действия зависят от ваших прав и возможностей браузера. Иллюстрации звонков используют демонстрационные данные; личные данные на снимках Messenger скрыты.

## 1. Разделы сайта

Верхнее меню открывает публичные библиотеки. Боковое меню после входа открывает личное пространство. На телефоне используйте кнопку меню **☰**.

| Раздел | Назначение |
|---|---|
| **Videos / Photos / Files** сверху | Публичные материалы, доступные также без входа. |
| **Home** | Главная страница и публичные материалы. |
| **My Videos / My Photos** | Ваши видео и фотографии, включая приватные. |
| **File Storage** | Ваши файлы и папки; материалы, которыми с вами поделились. |
| **Messages** | Личные и групповые разговоры, голосовые и видеозвонки. |
| **Settings / Statistics** | Профиль, пароль и статистика вашего контента. |

**Private** оставляет материал приватным. **Public** делает видео/фотографию публичными. Для файлов **Everyone** разрешает просмотр и скачивание всем, включая гостей. Доступ выбранным пользователям не делает материал публичным.

Обычный адрес приватной карточки сам по себе не дает гостю доступа. Для ограниченного по времени доступа используйте **Create 24-hour share link** (раздел 7).

## 2. Регистрация, вход и выход

1. Нажмите **Sign in → Create one**.
2. Укажите email. **First Name / Last Name** - необязательные имя и фамилия. Пароль при отправке заявки не создается.
3. Нажмите **Request account** и дождитесь одобрения администратора. После успешной отправки не отправляйте заявку повторно.
4. После одобрения войдите с email и **пустым паролем**. Это открывает первоначальную настройку пароля.
5. Заполните **New Password / Confirm New Password** и сохраните. Далее используйте созданный пароль; пустой пароль больше не принимается.

Если письмо не пришло, проверьте «Спам». Если email уже занят, войдите в существующий аккаунт или укажите другой адрес. После обычного входа открывается **Home**.

**Sign out** находится в меню пользователя. На общем устройстве завершайте работу этой кнопкой. Выход завершает активный звонок на этом устройстве и освобождает микрофон/камеру. Для завершения сеансов на других устройствах требуется соединение с сервером.

Messages и звонки используют один вход. Повторный вход для каждого звонка не требуется. Если после фонового режима появилась ошибка проверки сеанса, следуйте разделу 14.

## 3. Загрузка материалов

1. Откройте **My Videos**, **My Photos** или нужную папку в **File Storage**.
2. Нажмите **Upload** либо перетащите файлы в обозначенную область. Можно выбрать несколько файлов.
3. Для видео и фотографий выберите **Private / Public**. При одиночной загрузке можно указать название.
4. Дождитесь окончания передачи файлов, прежде чем закрывать вкладку.

Видео и изображения загружайте в соответствующий раздел. File Storage принимает разные типы файлов в пределах ограничений сайта и сохраняет их в открытую папку. Ошибка одного файла не отменяет загрузку остальных.

| Статус видео | Что делать |
|---|---|
| **Uploading** | Идет передача файла; оставьте вкладку открытой. |
| **Processing** | Сервер обрабатывает видео; можно пользоваться другими разделами. |
| **Ready** | Материал готов к просмотру. |
| **Processing Failed** | Прочитайте ошибку; используйте **Retry Processing**, если доступно, или **Delete Failed Upload** с подтверждением. |

Кнопки недоступны во время операции. Дождитесь результата, прежде чем повторять действие.

## 4. Просмотр и меню карточки

Нажмите карточку готового видео/фотографии. **Search**, фильтры и сортировка помогают найти материал. **Comfortable / Compact** меняют плотность галереи, если эти переключатели показаны.

Круглая кнопка **⋮** открывает меню видео, фотографии, файла или папки. Оно появляется поверх страницы и меняет положение у края экрана. Выбор действия закрывает меню; на телефоне нажмите кнопку пальцем.

У своих материалов могут быть **Edit**, **Rename**, **Share**, **Create 24-hour share link**, **Make public / Make private**, **Download** и **Delete**. У чужих показываются только разрешенные действия, например **Preview / Download**. **Move / Copy / Paste** относятся только к файлам и папкам.

**Edit** меняет настройки своих видео/фотографий; **Save** сохраняет их. У видео можно настроить изображение предварительного просмотра. **Rename** меняет название материала.

| Просмотр фотографий | Управление |
|---|---|
| Компьютер | **→ / Пробел** - следующая; **← / Alt + Пробел** - предыдущая. |
| Мышь | Колесо вниз - следующая; вверх - предыдущая. |
| Телефон / планшет | Свайп влево/вправо; двойное касание увеличивает область просмотра и возвращает обычный размер. |

Закрытие - **X / Close**. Другая реакция заменяет текущую, повторное нажатие выбранной снимает ее. Для добавления нужен вход; счетчик показывает участников.

## 5. Файлы: Copy, Paste и Move

В File Storage **New folder** создает папку; путь сверху и Назад/Вперед браузера помогают перемещаться. **Grid / List / Tree View** переключают представление. Search ищет названия в доступных папках; в публичной библиотеке - только публичные материалы.

| Действие | Порядок работы |
|---|---|
| **Copy** | Выберите Copy в меню своего файла/папки. Источник остается на месте. |
| **Paste / Paste here** | Откройте папку назначения; нажмите Paste в панели либо Paste here в доступном меню. Создается копия в текущей папке. |
| **Move** | Выберите Move, укажите папку назначения и подтвердите. После успешного переноса исходное место больше не содержит материал. |

Папка копируется/перемещается со всеми вложенными папками и файлами. Нельзя переместить папку в нее саму или в ее подпапку. Для назначения нужны права; чужая папка для просмотра не становится доступной для записи.

Буфер Copy временный, только для текущего аккаунта. Paste недоступен без действительного источника; после выхода, смены аккаунта или перезагрузки снова нажмите Copy. Удаление вставленной копии не очищает буфер исходного файла: его можно вставить снова, пока источник доступен.

При совпадении названий выберите **Replace** (заменить после отдельного подтверждения), **Keep both** (сохранить оба с разными названиями) или **Cancel**. Замененный материал переносится в Trash. Перезаписи без выбора нет.

**Preview** открывает поддерживаемые PDF, изображения, текст, CSV и Office. **Generating preview…** означает подготовку; оригинал не меняется. Для остальных форматов - Download. Папки скачиваются как ZIP в пределах ограничений. При частичной ошибке прочитайте сообщение и повторите оставшиеся шаги в том же окне.

## 6. Постоянный доступ: Share и Everyone

В меню своего материала выберите **Share**. Найдите получателей по email, добавьте их и нажмите **Save sharing**. Они могут просматривать и скачивать; управление остается у владельца.

**Everyone** разрешает доступ также гостям. Прочитайте предупреждение перед включением. Если доступ нужен отдельным людям, выберите этих получателей вместо Everyone.

| Действие с папкой | Как меняется доступ |
|---|---|
| Открыть доступ к папке | Его наследуют текущие и будущие файлы и подпапки. |
| Убрать прямой доступ у вложенного файла | Унаследованный доступ может сохраниться. Измените Share у указанной родительской папки. |
| Переместить файл | Прямые разрешения следуют за файлом; наследование зависит от новой папки. |
| Скопировать файл | Копия наследует доступ папки назначения; прямые разрешения источника не копируются. |

Чтобы отменить доступ, измените получателей/Everyone и сохраните. Уже скачанную получателем копию отозвать невозможно. Для временного доступа без изменения этих настроек используйте 24-часовую ссылку.

## 7. Временная ссылка на 24 часа

Владелец может дать гостю доступ к конкретному видео, фотографии, файлу или папке без входа в аккаунт.

1. Откройте **⋮ → Create 24-hour share link**.
2. В **Temporary Share Link** нажмите **Create 24-hour share link**, если ссылка еще не создана.
3. Проверьте **Valid until** - дату и время окончания доступа.
4. Нажмите **Copy Link** и передайте ссылку нужному человеку.
5. Чтобы закрыть доступ раньше, откройте это окно, нажмите **Revoke** и подтвердите.

**Копируйте полный адрес из окна.** Не убирайте `/video/`, если этот путь входит в созданную ссылку. Не заменяйте ее обычным адресом карточки.

Срок - **ровно 24 часа с создания**; просмотр его не продлевает. Обычные Private/Public и сохраненный Share не меняются. У материала одна временная ссылка: **Create new link** после подтверждения отключает предыдущую. Удаление материала или перенос в Trash прекращает доступ.

Скопируйте ссылку сразу после создания. При повторном открытии окна старый адрес не восстанавливается: сохраните полученную ссылку отдельно либо создайте новую через Create new link. Если Copy Link не сработала, выделите адрес и скопируйте вручную.

| Что увидит посетитель | Значение |
|---|---|
| Материал или содержимое указанной папки | Ссылка действительна. Доступа к другим папкам, профилю, настройкам и управлению нет. |
| **This share link has expired.** | Истекли 24 часа; попросите владельца создать новую ссылку. |
| **This share link is no longer available.** | Ссылка отозвана, заменена или материал недоступен. |

Любой получивший ссылку сможет открыть разрешенный материал до окончания срока. Не публикуйте ее, если хотите ограничиться конкретными получателями. Отзыв не удаляет уже скачанные копии.

## 8. Messages: найти пользователя

Откройте **Messages** после входа. В подборке - активные зарегистрированные пользователи, которым разрешено писать. Ваш аккаунт, недействительные аккаунты и люди, заблокированные в любой из сторон, не отображаются.

**На компьютере:** слева **Conversations / Groups** и **People**. People остается видимым во время разговора. **Search people** ищет по имени/email; нажмите человека. Списки разговоров и людей прокручиваются отдельно.

**На телефоне:** нажмите **New message**. Откроется **New conversation** с готовым списком. **Find registered users** фильтрует по имени/email. Нажмите человека: после успешного открытия разговора окно закрывается, показываются сообщения. **Back to conversations** возвращает к списку.

**More people** загружает следующую часть длинного списка. Искать можно с одного символа. Отображается имя/фамилия, а если их нет - email. Зеленый индикатор/Online показывает присутствие; Offline - отсутствие активного сеанса. Число возле человека/разговора - непрочитанные сообщения.

Выбор человека открывает существующий личный разговор или создает один новый; повторный выбор не создает копию. Текущий разговор выделен. Группы остаются в Conversations / Groups. Если человек стал недоступен после загрузки списка, появится ошибка; проверьте список снова.

## 9. Сообщения, группы и блокировка

Введите сообщение и нажмите **Send**. Через кнопку вложений добавьте файл; дождитесь окончания передачи. Для сообщения есть **Reply**, реакции; для своего - **Edit** и разрешенные варианты удаления.

Для группы откройте **New message → Group conversation**, заполните **Group name**, выберите участников и нажмите **Create group**. До 50 участников, включая вас. Выбранных людей можно убрать из черновика до создания.

Поиск слева ищет разговоры/имена участников. **Search conversation** ищет внутри разговора. Старые сообщения подгружаются при прокрутке вверх; **Go to latest messages** возвращает к новым.

| Действие | Последствие |
|---|---|
| **Mute / Unmute** разговор | Меняет уведомления для вас; сообщения и непрочитанные счетчики сохраняются. |
| **Block user** | Запрещает личные сообщения между вами в обе стороны. История и общие группы сохраняются. |
| **Blocked users → Unblock** | Снимает вашу блокировку. Блокировка второй стороны может продолжать действовать. |
| **Leave group** | Вы теряете дальнейший доступ; ваши отправленные сообщения остаются у остальных. |

Информация о группе позволяет владельцу/администратору управлять названием и участниками в пределах его прав. Только владелец назначает администраторов.

При Cancel/Close с черновиком **Keep Editing** сохраняет редактирование, **Discard** отбрасывает изменения. Внешний щелчок и Escape не закрывают задачу. Во время запроса дождитесь результата.

## 10. Голосовой или видеозвонок

В разговоре две кнопки: **Voice call** со значком телефона и **Video call** со значком камеры. Нужны активный аккаунт, разрешенный разговор и поддержка устройств браузером.

| Тип | Разрешения и вид |
|---|---|
| **Voice call** | Только микрофон. Имя/инициалы, статус, длительность и звуковые кнопки; большой области видео нет. |
| **Video call** | Микрофон и камера. Видео собеседника - основное; ваш небольшой зеркальный просмотр расположен поверх него. |

Входящий экран показывает **Incoming voice call / Incoming video call**. **Accept** принимает, **Decline** отклоняет. Есть звуковой сигнал, если браузер разрешает воспроизведение. **Enable call sound** разрешает сигнал; **Mute ringing / Unmute ringing** меняют только звук приглашения.

**Mute / Unmute** выключает/включает ваш микрофон, **Devices** открывает устройства, **End call** завершает звонок. Звонок поддерживает до четырех участников, включая вас; в большей группе кнопки могут быть недоступны.

Голосовой звонок в этой версии не переводится в видео одной кнопкой. Для видео завершите его и начните Video call. Не закрывайте вкладку во время звонка.

## 11. Видео: камера и полный экран

Видео собеседника - основное изображение. Ваш просмотр меньше и по умолчанию справа сверху; он зеркальный, удаленное изображение - нет. Перетащите свой просмотр в безопасный угол или нажмите **Move self-view to next corner**.

| Кнопка | Что меняется |
|---|---|
| **Hide self-view / Show self-view** | Только ваш экран. Собеседник продолжает получать вашу камеру. |
| **Camera off / Camera on** | Передача изображения вашей камеры. Звук и звонок продолжаются. |
| **Expand call / Exit fullscreen** | Разворачивает весь звонок с видео, своим просмотром и кнопками; возвращает обычное окно без завершения звонка. |
| **Share screen / Stop sharing** | Демонстрация экрана, если поддерживается. Область и разрешение выбираются в системном окне. |

При выключенной камере изображение закрывается черным фоном с **Camera off**; последний кадр не должен оставаться. Включение автоматически возвращает живое видео. То же действует для вашего просмотра. Демонстрация экрана может оставаться видимой, когда камера выключена.

Полный экран сохраняет пропорции изображения, поэтому черные поля допустимы. Кнопки внизу остаются доступны. Выход из полного экрана не означает End call. Если полный экран браузера недоступен, звонок занимает его видимую область; системные панели могут оставаться.

## 12. Звонок на телефоне: экран и звук

Поворот телефона меняет расположение без перезапуска звонка. В горизонтальном положении элементы компактнее, собственный просмотр меньше, кнопки внутри видимой области. **Expand call** использует доступную площадь. Длинные настройки в Devices прокручиваются отдельно.

| Предпочтение на телефоне | Когда действует |
|---|---|
| Video: громкая связь | Если браузер распознает и позволяет выбрать громкоговоритель. |
| Voice: разговорный динамик | Если браузер распознает и позволяет выбрать внутренний динамик. |
| Гарнитура/Bluetooth | Системный маршрут сохраняется; приложение не должно самовольно переключать звук на телефон. |

**Speaker on** выделен только при подтвержденном громкоговорителе. **Speaker off** означает подтвержденный разговорный динамик. Повторное нажатие переключает между ними, если доступны оба.

Нейтральная **Speaker** и подпись **Audio output** могут означать системный маршрут, гарнитуру или неопределенный выход. Это не подтверждение громкой связи. **Speaker / Devices** открывают варианты; **Choose audio output** появляется только при поддержке.

На части телефонов Android/Firefox/Chrome и iPhone/Safari сайт не может выбрать физический динамик. Используйте штатные средства телефона или гарнитуру; звонок сохраняется. На компьютере используется обычный системный выход и доступный выбор в Devices.

Выход сохраняется на время звонка; полный экран, поворот и скрытие своего просмотра его не сбрасывают. Если устройство отключилось, проверьте системный маршрут и выберите доступный выход заново.

## 13. Настройки, статистика и удаление

**Settings:** меняйте First Name/Last Name и сохраняйте профиль. **Change Password** требует текущий пароль, новый и подтверждение. **Statistics** показывает ваши материалы, просмотры, реакции, загрузки и место; выберите период графиков. **Admin Console** только для администраторов.

Перед удалением проверьте название или количество материалов. Удаление папки включает содержимое. **Cancel** отменяет; во время запроса кнопки блокируются. Ошибка остается в подтверждении: повторяйте только незавершенные шаги по сообщению.

| Где удаляете | Результат |
|---|---|
| **My Videos / My Photos → Delete**, неудачная загрузка | Окончательное удаление материала и связанных файлов. Восстановления через сайт нет. |
| **File Storage → Delete / Move to Trash** | В Trash. **Restore** возвращает и предлагает выбор при конфликте названий. |
| **Trash → Delete forever / Delete All** | Окончательно выбранный материал или содержимое Trash согласно подтверждению. |
| **Delete for myself** сообщение | Карточка целиком исчезает только у вас. Остальные сохраняют сообщение и вложения. |
| Свое **Delete for everyone** | Карточка исчезает у всех; реакции удаляются, доступ к вложениям закрывается. Отметка об удаленном оригинале остается только в ответах на него. |
| **Clear messages** | Подтвержденная история только для вас или всех, если разрешено. Новые сообщения не входят в подтвержденный диапазон. |
| Личный **Delete chat** для себя | Скрывает разговор. Выбор того же человека или новое сообщение возвращает его без создания копии. |

Удаление группы для себя означает выход; для всех нужно соответствующее право. Hide self-view, Mute и выход из полного экрана не завершают звонок.

## 14. Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Пользователя нет в People | Имя/email, More people, активность и блокировки. Администратор проверяет одобрение аккаунта. |
| Ссылка дает **404** | Скопируйте полный адрес через Copy Link с `/video/`, если он указан. Если верный адрес дает 404, сообщите владельцу/администратору; гостю вход не нужен. |
| Ссылка истекла/отозвана | Владелец создает новую. Просмотр и обновление страницы старую не продлевают. |
| После Delete папка пуста, но файл в Trash | Это мягкое удаление. Restore возвращает его. Исходник можно вставить снова; живое совпадение требует Replace / Keep both / Cancel. |
| Paste недоступен | Скопируйте существующий свой материал, откройте разрешенную папку, очистите поиск и дождитесь текущей операции. |
| Камера/микрофон недоступны | Разрешения сайта, устройства в Devices, другое приложение. Для Voice камера не нужна. |
| Нет входящего сигнала | Enable call sound, Mute ringing и громкость устройства. |
| Нет звука собеседника | Громкость, Audio output/гарнитура, его микрофон. Нейтральная Speaker не означает включенную громкую связь. |
| После фонового режима Sign in | Вернитесь во вкладку, проверьте связь. Сохраните черновики/дождитесь загрузок, затем обновите страницу. Если сеанс закончился, войдите снова. |
| Sign out не завершает работу | Проверьте меню аккаунта. Если личный раздел доступен после обновления, обратитесь к администратору; не оставляйте аккаунт на общем устройстве. |
| Горизонтальный звонок не помещается | Закройте Devices, используйте Expand call, проверьте масштаб браузера. Сообщите модель телефона, браузер и ориентацию, если проблема остается. |

Для помощи укажите раздел, действие, точный текст ошибки. Для звонка добавьте Voice/Video, браузер, устройство, гарнитуру и переход в фон. Не публикуйте пароль, приватную переписку и действующие временные ссылки.
